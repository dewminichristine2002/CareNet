## CareNet360 – Vulnerability Assessment and Remediation

This repository contains the **CareNet360** project used for the SE4030 – Secure Software Development assignment. The project was assessed for security vulnerabilities, and appropriate security fixes were implemented and tested.

## 4. Security Assessment

The CareNet360 application was analyzed using multiple security testing tools to identify vulnerabilities in the source code and application.

The identified vulnerabilities were reviewed, remediated, and tested to verify that the implemented fixes successfully addressed the identified security issues.

## 5. Security Testing Tools

The following security testing tools were used:

- SonarQube
- Semgrep
- CodeQL
- OWASP ZAP

## 6. OAuth / OpenID Connect

OAuth and OpenID Connect (OIDC) security mechanisms were implemented and evaluated as part of the secure software development requirements.

## 8. Project Purpose

The purpose of this project is to demonstrate secure software development practices by identifying security weaknesses in an existing application, implementing appropriate remediation techniques, and verifying the effectiveness of the implemented security controls.
